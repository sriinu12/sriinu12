# Jumping Ball Runner

Jumping Ball Runner is a colorful endless runner where a cartoon ball hops over obstacles.

## Goal
Jump over obstacles to survive as long as possible.

## Features
- Increasing speed to ramp up the challenge
- High score tracking to beat your best run
- Retry button to jump back in after a crash
- Funny sound effects for jumps, crashes and high scores
- Colorful UI with parallax scrolling backgrounds
- Cartoonish characters that are fun to watch
- Designed to be enjoyable for everyone

## Controls
- **Space**: Jump
- **R**: Retry after game over
- Close the window to exit

## Run the Game
```bash
python jumping_ball_runner.py
```
Ensure `pygame` and `numpy` are installed. The game opens a window and is best experienced with sound.
